# Clinevo Inbox AI

Smart Inbox Assistant prototype for the Clinevo Technologies AI Full Stack / GenAI assignment.

The system is designed around the requested flow:

- Angular reviewer UI
- Spring Boot orchestration/API
- Python FastAPI AI/document service
- Oracle persistence and audit trail

All sample/test data must be synthetic. No real patient or client data belongs in this repository.

Development is tracked through GitHub issues and feature branches; changes are merged to `main` through pull requests.
